1. 什麼是 /cmd_vel？
----------------------------------------------------------------
全名：Command Velocity (速度指令)
用途：這是 ROS 機器人導航中最標準的「控制話題 (Topic)」。
      任何想要讓車子移動的程式 (不管是鍵盤控制、導航演算法、還是你的 Python 腳本)，
      都必須把指令發送到這個話題上。

* 訊息格式 (Type)：geometry_msgs/Twist
* 核心概念：它控制的是「速度」，而不是「位置」。
            (發送 0.0 代表立刻煞車，而不是回到原點)

----------------------------------------------------------------
2. 訊息結構詳解 (geometry_msgs/Twist)
----------------------------------------------------------------
一個 Twist 訊息包含兩大區塊：Linear (線性速度) 與 Angular (角速度)。

(A) Linear (線性速度) - 控制「位移」
    單位：公尺/秒 (m/s)

    * linear.x : [前進/後退]  <-- 最常用！
        (+) 正數：車頭向前進 (Throttle)
        (-) 負數：倒車
        (0) 零  ：煞車

    * linear.y : [橫向平移]
        (+) 正數：整台車向左橫移
        (-) 負數：整台車向右橫移
        * 注意：只有全向輪 (Mecanum Wheel) 的車子才支援此功能。
          一般兩輪差速或阿克曼轉向的車子，此數值必須為 0。

    * linear.z : [垂直升降]
        * 用途：無人機 (Drone) 升高降低用。
        * 地面機器人：永遠為 0。

(B) Angular (角速度) - 控制「旋轉」
    單位：弧度/秒 (rad/s)  *** 注意：不是角度 (Degree) ***

    * angular.x : [側傾 (Roll)]
        * 車身左右翻滾，地面車輛不使用。

    * angular.y : [俯仰 (Pitch)]
        * 車頭翹孤輪或點頭，地面車輛不使用。

    * angular.z : [偏航 (Yaw)]  <-- 最常用！
        (+) 正數：向左轉 / 逆時針 (Counter-Clockwise)
        (-) 負數：向右轉 / 順時針 (Clockwise)
        (0) 零  ：直走，不轉彎

----------------------------------------------------------------
3. 單位換算小抄 (Cheat Sheet)
----------------------------------------------------------------
由於 Angular 用的是「弧度」，很多新手會設錯數值導致車子瘋狂旋轉。

* 1.0 rad/s  ≈ 每秒轉 57 度 (轉很快)
* 0.5 rad/s  ≈ 每秒轉 28 度 (正常轉彎速度)
* 0.1 rad/s  ≈ 每秒轉 5.7 度 (微調修正)
* 3.14 rad/s ≈ 每秒轉 180 度 (瞬間掉頭)

1. 轉向控制 (Steering):
   目標: 將 position.x 收斂至 0 (Tag 置中)
   公式: angular.z = -1 * KP_ANGULAR * position.x

   * 符號邏輯解析:
     - 當 Tag 在左邊 (position.x 為負)
     - 我們希望車子左轉 (angular.z 為正)
     - 因此需要補一個負號: (-1) * (負誤差) = 正轉向指令

2. 前進控制 (Throttle):
   目標: 將 position.z 收斂至 TARGET_DIST (保持距離)
   公式: linear.x = KP_LINEAR * (position.z - TARGET_DIST)

   * 符號邏輯解析:
     - 當 (現在距離 > 目標距離) -> 誤差為正 -> linear.x 為正 (前進追)
     - 當 (現在距離 < 目標距離) -> 誤差為負 -> linear.x 為負 (後退讓)
