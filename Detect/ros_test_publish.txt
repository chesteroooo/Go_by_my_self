ROS 遠端視覺導航通訊協議 (Clean Pair Version)
================================================================
[Topic] /target_info
[Type]  geometry_msgs/Pose

我們將 Pose 分為「控制數據 (Position)」與「識別數據 (Orientation)」兩區。

----------------------------------------------------------------
(A) Position - 控制數據區 (Control Data)
----------------------------------------------------------------
負責告訴車子該怎麼移動。

* msg.position.x : [橫向誤差] (Horizontal Error)
    - 單位：像素 (Pixels)
    - 用途：決定左右轉 (P Controller)。

* msg.position.z : [直線距離] (Distance)
    - 單位：公尺 (Meters)
    - 用途：決定前進後退 (P Controller)。

* msg.position.y : [預留]
    - 目前未使用 (0.0)。

----------------------------------------------------------------
(B) Orientation - 識別數據區 (Identity Data)
----------------------------------------------------------------
負責告訴程式現在看到的是誰，以及資料是否有用。

* msg.orientation.x : [Member ID 1]
    - 說明：Pair 中的第一個 Tag ID。
    - 格式：Float (e.g., 0.0)。

* msg.orientation.y : [Member ID 2]
    - 說明：Pair 中的第二個 Tag ID。
    - 格式：Float (e.g., 1.0)。
    - 組合：與 ID 1 結合成 Pair Key (e.g., "0_1")。

* msg.orientation.w : [有效旗標] (Valid Flag)
    - 1.0 : [有效] 偵測到 Pair，可以移動。
    - 0.0 : [無效] 視野中無目標，緊急停車。
